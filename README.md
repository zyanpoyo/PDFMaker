# 複合機 印刷拡縮検証用PDF生成ツール (PDFMaker)

**Version: 1.0.0**

Windows 11 上で単体動作する「複合機 印刷拡縮検証用PDF生成ツール」のデスクトップGUIアプリケーションです。
完全オフライン環境で動作し、PyInstallerにより単一のスタンドアロン `.exe` ファイルとして実行・配布可能です。

---

## 1. 特徴・主な機能

- **JIS規格B列寸法の厳密採用**:
  ISO規格ではなく、国内で広く用いられるJIS規格寸法（B4_JIS: 257×364mm、B5_JIS: 182×257mmなど）をミリメートル単位で厳密にベクター描画します。
- **高精度ベクター描画**:
  ReportLab を用い、線幅 0.25 pt（極細ヘアライン、Butt-Cap端点）で外枠・内枠および精密な測定用スケールバーを描画します。
- **自動拡縮抑止（ViewerPreferences）**:
  PDF Catalog に `PrintScaling=None` を設定し、印刷時にビューアーが勝手に拡縮するのを抑止します。
- **狭小内枠への自動適応**:
  A5縦（外枠0.5mm/内枠50mm）などの狭い内枠でも、文字幅・行間を計算して等幅フォント（Courier）の折り返し・縮小、およびスケールバー長（100mm → 50mm → 30mm等）の自動選択を行います。
- **直感的なGUI（Windows 11 ネイティブ調）**:
  - リアルタイムプレビューCanvas（用紙比率・外枠・内枠・ラベル領域の視覚化）
  - ページの追加・再編集（選択行の更新）・複製（Ctrl+D）・順序入れ替え・削除
  - プリセット一括追加（全サイズ縦横10p / 全縦5p / 全横5p）
  - 全ページマージン一括上書き（外枠のみ／内枠のみの個別指定可能）
  - ページ構成JSONの保存・読込、前回の入力値や保存先フォルダの自動記憶
  - PDF生成完了後の「PDFを開く」「フォルダを開く」ダイアログ

## 3. 印刷検証時の重要事項（測定方法）

> [!IMPORTANT]
> 複合機の印刷拡縮率・ズレを正確に検証するため、印刷時は以下の設定を必ずご確認ください。
> 1. **印刷ダイアログの倍率（「実際のサイズ / 100%」を厳守）**:
>    Acrobat Reader などの印刷ダイアログにおいて、**「実際のサイズ（100%）」** を必ず選択してください。
>    - **理由**: 「用紙に合わせる」が有効になっていると、ビューアー側が複合機の非印字領域（端から3〜5mm）内に収めようとしてPDF全体を勝手に約95〜97%へ縮小してしまいます。その結果、「ソフトによる意図しない縮小」が混入し、複合機自体の物理的な送り誤差やエッジ欠け限界の検証ができなくなります。
> 2. **測定と判定**:
>    - **外枠（Outer Frame）**: 用紙端からのエッジ欠け（非印字領域）や印刷位置の偏り（左右・上下の余白ズレ）を測定します。等倍印刷することで、外枠の欠け位置から複合機の物理的な非印字限界（mm）が判明します。
>    - **内枠・スケールバー**: 金属製直定規等を用いて、スケールバーの長さ（100mmまたは50mm/30mm）を測り、設計値との誤差から複合機の主走査・副走査方向の拡縮率（%）を算出します。ソフト側による変形が排除されているため、複合機のローラー送り精度そのものを正確に特定できます。

## 4. 開発環境・前提基盤

本ツールの開発・ビルドには以下の基盤環境を使用します。

### (1) システム実行基盤
- **Python**: 3.10 以上（推奨: Python 3.13）
  - **winget によるインストールコマンド**:
    ```powershell
    winget install Python.Python.3.13
    ```
    *※ インストール時は「Add python.exe to PATH」および標準オプションの「tcl/tk and IDLE（Tkinter GUI用）」を含めてインストールしてください。*
- **外部ランタイムについて**:
  - **Node.js や C/C++ コンパイラ等の追加ツールは一切不要**です（Python標準機能およびPure Python / Wheelライブラリのみで完結）。

### (2) 開発・ビルド・テスト用ツール (`requirements.txt` 以外の追加ライブラリ)
単一exe化や自動テスト、アイコン生成に必要なツール群は `requirements-dev.txt` にまとめられています。

- **含まれるツール**:
  - `pyinstaller`: 配布用スタンドアロンexe生成ツール
  - `pytest`: 描画精度・寸法検証テストフレームワーク
  - `pypdf`: 生成されたPDFのMediaBox（ミリ寸法）自動検証ツール
  - `pillow`: マルチ解像度アプリアイコン（`app.ico`）生成ツール

- **開発用ツールのインストールコマンド**:
  ```powershell
  # 1. 仮想環境の作成と有効化
  py -m venv .venv
  .\.venv\Scripts\activate

  # 2. 開発・ビルド用ライブラリのインストール (実行用 requirements.txt を除く)
  python -m pip install -r requirements-dev.txt
  ```

## 5. 単一exeファイルのビルド手順

### 方法A: ワンクリックバッチによるビルド (推奨)
プロジェクト直下の `build_exe.bat` をダブルクリックして実行します。
自動的に仮想環境の構築、ライブラリのインストール、自動テスト（pytest）の実行、および PyInstaller によるexeパッケージングが行われます。

### 方法B: コマンドラインによる手動ビルド
コマンドプロンプトまたは PowerShell を開き、以下のコマンドを実行します。

```powershell
# 1. 仮想環境のセットアップと依存ライブラリ導入
py -m venv .venv
.\.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt -r requirements-dev.txt

# 2. 自動テストの実行 (省略可)
python -m pytest -v

# 3. 単一スタンドアロンexeのビルド
python -m PyInstaller --onefile --noconsole --clean --icon=app.ico --add-data "app.ico;." --name "PDFMaker" app.py
```

ビルド完了後、`dist\PDFMaker.exe` が生成されます。
このexeファイル単体で、Pythonや追加ランタイムのない他のWindows 11 PCへ配布して動作させることができます。
